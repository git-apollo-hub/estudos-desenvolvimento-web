# 🚀 Estudos de Desenvolvimento Web

> Repositório criado para documentar minha jornada de aprendizado em **PHP** e **JavaScript**, reunindo teoria, exercícios e projetos desenvolvidos ao longo do curso.

O objetivo deste projeto é evoluir dos conceitos básicos até o desenvolvimento de aplicações web completas, construindo também um portfólio público no GitHub.

---

# 📚 Conteúdo do Repositório

Atualmente o repositório está organizado da seguinte forma:

```text
estudos-desenvolvimento-web/
├── aula01-variaveis
├── aula02-condicionais
├── aula03-loop
├── aula04-funções
├── aula05-projetoCalculadora
└── exercicios-aula01-a-aula04
```

Cada pasta representa uma etapa do aprendizado e contém:

* 📖 Material da aula
* 💻 Exercícios em PHP
* 💻 Exercícios em JavaScript
